LibreQuake data
===============

These six PAK files (pak0.pak … pak5.pak) are the LibreQuake game data,
extracted from the `lq.bin` archive distributed with Qwasm.

LibreQuake is a free and open replacement data set for Quake. The project
states that its art and other media are released under the Modified BSD
License, while the game code is GPL. It contains no id Software data.

  Project: https://github.com/lavenderdotpet/LibreQuake
  Website: https://librequake.queer.sh/

The Quake engine itself is Qwasm by Gregory Maynard-Hoare:

  https://github.com/GMH-Code/Qwasm

If you own the original Quake, you can load your own PAK0.PAK and/or
PAK1.PAK from the cabinet's boot panel instead. Those files are not
included here and are not redistributed by this arcade.

The `license.txt` in the parent directory is the shareware license that
ships with the Qwasm distribution; it does not apply to these LibreQuake
PAKs.
