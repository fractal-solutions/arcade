Slide around the pad for all eight directions. JUMP, FIRE and JET are independent, so you can hold two at once.

Progress saves automatically at every new level. Haptics are on by default where supported.

Dangerous Dave was created by John Romero and published by Softdisk in 1990. This browser build recompiles the open-source C reimplementation deadly-dave (GPL-3.0) with its original level and tile data.

Every game tick, collision test and pixel is produced by C compiled to WASM. JavaScript only forwards input and paints the framebuffer.
