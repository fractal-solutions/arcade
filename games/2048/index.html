Rules recovered from the binary
  • Tiles are stored as exponents: 1 → 2, 2 → 4 … 11 → 2048.
  • Spawn: rand() % empty_count chooses the cell.
  • Spawn value: (rand() == 0x7fffffff) ? 2 : 1 — a 4 is roughly a 1-in-2³¹ event.
  • A tile merges at most once per move; merged exponent increases by one.
  • Score is doubled: score += 2 << newExponent, not the usual 1 << n.
  • Win when a merged tile reaches exponent 11 (2048).
  • Game over when the board is full and no orthogonal neighbours match.
Differential verification

The original aarch64 core was loaded with a tiny C harness (dlopen + libretro callbacks). Its rand() was interposed with musl's LCG so both engines saw the same seed and spawn stream. 20 seeds × 300 moves produced byte-identical boards, scores and state transitions.

Ported from rea-lab: an aarch64 libretro core → WebAssembly reverse-engineering lab. Original 2048 by Gabriele Cirulli; this engine is an independent reconstruction.
