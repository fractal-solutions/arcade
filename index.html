Authentic, not remastered

Quake runs the original engine compiled to WebAssembly. Dangerous Dave runs an open-source C reimplementation; Prince of Persia 2 is a static recompilation of the Macintosh binary; 2048 is a reverse-engineered WASM engine; Keen 4, Duke Nukem II, the DOS vault and the bring-your-own DOS cabinet run real DOSBox in WebAssembly. No ROM hacks, no redrawn sprites.

Quake, ready to go

No data hunt required: the cabinet bundles LibreQuake, a free and open data set with maps, bots and a campaign. Own the original? Load your own PAK0.PAK / PAK1.PAK and play that instead.

More classics, done right

Quake II, Quake III Arena, Capitalism II/Lab and GTA 2 are reference entries only; their engines, Windows installs or data are not bundled, and the cards do not navigate off-site. The free Carmageddon demo still fails to boot in this DOSBox build, so it is not marked as playable. The Flash filter now opens a local vault of 26 SWF games, running offline in Ruffle with no outbound game links; the vault also keeps a bring-your-own-SWF player for anything else you want to load.

Saves that stay put

High scores, unlocked levels and in-game save slots live in your browser's storage. Nothing is uploaded. Clear site data and the arcade forgets you.

One-time setup

Add your Prince of Persia 2 data

The web engine contains no game files. You need a legally owned copy of the Macintosh release and a desktop with unar and python3.

  1. Prepare the archive 
    git clone https://github.com/mac-recomp/pop2
cd pop2
tools/prep-web-data.sh "Prince_Of_Persia2.sit" /tmp/pop2
mv /tmp/pop2/vol /tmp/pop2/pop2
tar --format=ustar -czhf pop2-data.tar.gz -C /tmp/pop2 app data pop2
  2. Open the game

    Launch the cabinet and drop pop2-data.tar.gz onto the page, or paste a direct link to it.

  3. Play offline later

    The archive is cached in IndexedDB. Next visit starts instantly. Use Forget data inside the game to remove it.

Already built the archive? Open the cabinet and drop it in. Hosting the data yourself? Append ?data=pop2-data.tar.gz to the game URL.

One-time setup

Add a DOS game

Commander Keen 4 and Duke Nukem II already ship with their freely distributable shareware episodes. The generic DOS cabinet is a DOSBox build running in WebAssembly; for anything else you supply a .jsdos bundle made from a game you own.

  1. Gather the game files

    Put the game's folder somewhere convenient. The main executable and its data files must sit together.

  2. Add a DOSBox config

    Create .jsdos/dosbox.conf inside the folder with a [autoexec] section that mounts C: and starts the game:

    [autoexec]
mount c .
c:
GAME.EXE
  3. Zip it as .jsdos

    Zip the folder contents (not the folder itself) and rename the archive to mygame.jsdos. Then open the cabinet and choose the file.

Saves made inside the game are kept in this browser's storage. Use the js-dos menu to export a save bundle if you want a portable copy.

Bundled data · optional PAKs

Play Quake your way

The cabinet contains Quake's WebAssembly engine and the free LibreQuake data set. It starts with no downloads and no file picker. If you own the original game, you can load its PAK files instead.

  1. Launch LibreQuake

    Open the cabinet and press Launch LibreQuake. The bundled maps, bots and campaign run entirely in the browser.

  2. Or use your own PAKs

    Choose Load PAK files, pick PAK0.PAK (shareware) or PAK0.PAK + PAK1.PAK (full game), then press Play supplied PAKs. Nothing is uploaded.

  3. Phone in landscape

    Start the game, tap Fullscreen and rotate. The PSP-style overlay gives you a left movement stick, a right look pad, fire / jump / menu / status buttons and shoulder weapon switches. The Pad button toggles it on desktop.

Shareware Quake data is not redistributed by this arcade; supply it from your own copy. LibreQuake is an independent free data project. The Qwasm engine and preparation instructions are included locally in this repository.

Bring your own ROM

Add a Game Boy game

The cabinet ships with the mGBA core compiled to WebAssembly and no commercial ROMs. Load a .gba, .gb or .gbc file you own, or a freely distributable homebrew release. The file is read in this tab and never uploaded.

  1. Choose a ROM

    Open the cabinet and drop a ROM onto the picker, or press Choose ROM. Files up to 64 MB are accepted.

  2. Play with keys or touch

    On a keyboard: arrows move, Z = A, X = B, Q / E = L / R, Enter = Start and V = Select. Touch devices get a D-pad and face buttons; the same physical keys still work.

  3. Go fullscreen

    Use the cabinet's Fullscreen button. The touch controls stay on the dark rails outside the game screen in landscape, and below it in portrait.

Saves and save states stay in this browser's storage. Only homebrew, public-domain test ROMs or cartridges you dumped yourself should be used; commercial ROMs are not distributed by this arcade. Hosting a ROM next to the arcade? Append ?rom=game.gba to the cabinet URL.
